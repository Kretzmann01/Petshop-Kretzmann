# Petshop Kretzmann — Fase 2

**Slogan:** O spa do seu cãopanheiro.

Projeto acadêmico de Fundamentos de Sistemas Web, dando continuidade à Fase 1.

## Estrutura
- `index.html` — página inicial e carrossel Bootstrap.
- `produtos.html` — seis produtos em três categorias.
- `servicos.html` — banho e tosa.
- `cadastro.html` — cadastro do cliente e do pet.
- `agendamento.html` — escolha do serviço, método, data e horário.
- `contato.html` — contato.
- `css/style.css` — estilos próprios.
- `js/script.js` — funções JavaScript.
- `documento-fase2.md` — documentação da fase.

## Requisitos atendidos
- CSS e Bootstrap.
- Carrossel Bootstrap.
- Função temporal com relógio.
- Formulário com text, email, tel, radio, checkbox, number e campos obrigatórios.
- Cadastro de cliente e pet.
- Banho e tosa.
- Agendamento por tele-busca ou entrega do pet no local.
- Calendário (`date`) e horário (`time`).
- Acessibilidade com `alt`, `label`, `aria-label` e `aria-live`.
- Código separado em HTML, CSS e JavaScript.

## Como editar no VS Code
Abra a pasta no VS Code e altere os arquivos `.html`, `css/style.css` ou `js/script.js`. Salve e teste `index.html` no navegador.

## Publicação
O projeto pode ser publicado no GitHub e GitHub Pages mantendo `index.html` na raiz do repositório.
