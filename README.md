# Petshop Kretzmann — Fase 1

**Slogan:** O spa do seu cãopanheiro.

Projeto acadêmico da disciplina de Fundamentos de Sistemas Web.

## Objetivo

Desenvolver uma plataforma online para um petshop, utilizando HTML5 para estruturar a apresentação de produtos e serviços.

A plataforma apresenta produtos divididos em três categorias:

1. Acessórios;
2. Rações não perecíveis;
3. Produtos de higiene e limpeza.

Também apresenta o serviço de banho e tosa com as opções de atendimento com ou sem tele-busca.

## Estrutura do projeto

```text
petshop-kretzmann-fase1/
│
├── index.html
├── produtos.html
├── servicos.html
├── contato.html
└── README.md
```

## Arquivos HTML

- `index.html` — página inicial.
- `produtos.html` — catálogo de produtos.
- `servicos.html` — banho e tosa.
- `contato.html` — informações de contato.

Todos os arquivos HTML estão disponíveis separadamente no repositório do projeto.
